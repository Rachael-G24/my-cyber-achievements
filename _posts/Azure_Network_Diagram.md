# Network Diagram
## MS Azure Cloud Environment Setup
### September 30, 2024
---

One of the learning modules in my cybersecurity bootcamp focused on building, designing, and securing my own virtual network using MS Asure. I learned how to create and host three virtual machines. As a cohort, my classmates and I learned to include an Ansible jump box and Docker containers. 

We implemented firewall rules and a load balancer as well. 

Below is an image of the network map I created using draw.io. The network map was a culminating assignment for this particular module. The map needed to include the following:
- Azure resource group
- Virtual network with IP address range
- Subnet range
- Flow of HTTP, SSH, etc., traffic
- Security group blocking traffic
- Load balancer
- All three VMs that I've launched
- Where Docker and Ansible are deployed

The network map is a demonstration of all I learned about cloud computing and the networking principles I applied to the cloud environment. I still have these VMs up and running and continue to practice my knowledge and skills on MS Azure.
